# v0.1 MVP Specification

## Product position

This app is a companion launcher for Google Pixel 10a + Pixel Launcher.
It does not replace Pixel Launcher and must not declare itself as a HOME launcher.

The app supplements Pixel Launcher's weak points:

- app categorization
- multi-tag filtering
- tag-based app lists
- unclassified app cleanup
- pinned shortcuts that open tag-filtered lists

## v0.1 scope

### Must have

- List launchable apps
- Identify app entries by packageName + className
- Show app label and icon
- Launch selected app
- Create tags
- Assign multiple tags to an app
- Remove tags from an app
- Show apps by selected tag
- Show unclassified apps
- Support AND filtering for multiple selected tags
- Basic Material You / dynamic color UI
- Create a minimum pinned shortcut that opens a tag-filtered app list

### Must not have

- HOME launcher replacement
- QUERY_ALL_PACKAGES as mandatory requirement
- UsageStatsManager
- Widget
- Backup/restore
- Advanced icon cache
- Google Play policy work
- OR filter UI
- Cloud sync

## Data model draft

### launcher_apps

- packageName: String
- className: String
- label: String
- isInstalled: Boolean
- lastSeenAt: Long

Primary key:

- packageName
- className

### tags

- tagId: Long
- name: String
- sortOrder: Int

### app_tags

- packageName: String
- className: String
- tagId: Long

Primary key:

- packageName
- className
- tagId

## App discovery

Use Intent.ACTION_MAIN + Intent.CATEGORY_LAUNCHER to query launchable activities.
Do not start with QUERY_ALL_PACKAGES.
Do not declare HOME category.

## Undo/Redo

Not required in v0.1.
For later phases, implement one-step undo/redo in ViewModel state first.
Do not create an undo_redo database table in v0.1.

## Shortcut

v0.1 should include a minimal pinned shortcut proof of concept.

Shortcut action:

- open this app
- apply predefined tag filter
- show matching app list

## Design

Use Kotlin, Jetpack Compose, Room, ViewModel, Flow.
Prefer simple architecture over overengineering.
